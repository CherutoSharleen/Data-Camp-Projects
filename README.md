## Educational mini-project in this repository

- **Path:** `mini_recommenders/knn_items`
- **Focus:** k-NN style item recommendation using cosine similarity and explanation helpers.
- **Run:** `cd mini_recommenders/knn_items && python cli.py`
- **Test:** `cd mini_recommenders/knn_items && python -m unittest discover -s tests -p "test_*.py"`
